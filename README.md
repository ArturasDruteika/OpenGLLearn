# OpenGL Learn

This repository can act as a simple learning tool that shows the progress of what a developer needs to know and how to use it to render a simple solar system with realistic lighting.

I do not know how far I will go with these tutorials, but I will try to explain things the way I understand them, so there might be some inaccuracies.

In my opinion, the following resources explain rendering and OpenGL much better. If you want to gain deeper knowledge, I strongly recommend reading and watching them:

1. [__Cherno__](https://www.youtube.com/@TheCherno) videos about [OpenGL](https://www.youtube.com/watch?v=W3gAzLwfIP0&list=PLlrATfBNZ98foTJPJ_Ev03o2oq3-GGOS2) and [Game Engine](https://www.youtube.com/watch?v=JxIZbV_XjAs&list=PLlrATfBNZ98dC-V-N3m0Go4deliWHPFwT)
2. [__Learn OpenGL__](https://learnopengl.com/)

These resources, at least for me, had the biggest influence and gave me the biggest fundamental understanding of rendering and OpenGL.
